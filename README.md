</p>📌 About the Project

Sales Performance Analysis is a data analytics project developed using Microsoft Excel and Power BI. This project analyses sales data to understand business performance through revenue, profit, product sales, customer behaviour, and regional performance.

🎯 Project Objectives

- 💰 Calculate total revenue and profit.
- 📦 Analyse total quantity of products sold.
- 🏆 Identify top-performing products and customers.
- 🌍 Analyse sales performance by region.
- 🛒 Compare revenue across product categories.
- 📈 Understand monthly revenue and profit trends.
- 🎯 Track sales targets and returns.

🛠️ Tools & Technologies

Tool| Purpose
📗 Microsoft Excel| Data storage and preparation
📊 Power BI| Interactive dashboards
🧮 DAX| Measures and calculations
🔄 Power Query| Data cleaning and transformation

📂 Dataset Information

The project contains seven tables:

1. SALES
2. CUSTOMER
3. PRODUCT
4. EMPLOYEE
5. STORE
6. RETURNS
7. TARGET

🧹 Data Preparation

Data was imported into Power BI and prepared using Power Query.

- Promoted column headers.
- Checked column data types.
- Checked missing values and errors.
- Reviewed data quality.
- Prepared tables for analysis.
